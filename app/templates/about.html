O projekcie

Cel projektu

Celem projektu bylo stworzenie systemu klasyfikacji artykulow prasowych w kontekscie wykrywania Fake News. Aplikacja wykorzystuje techniki przetwarzania jezyka naturalnego (NLP) oraz uczenia maszynowego (ML) do automatycznej analizy tresci

Pipeline przetwarzania danych
  1. Wprowadzenie danych: Uzytkownik wprowadza tytul oraz tresc artykulu
  2. Preprocessing: Tekst poddawany jest czyszczeniu oraz normalizacji == usuwanie znakow specjalnych == przeksztalcenie na male litery == tokenizacja
  3. Ekstrakcja cech - TF-IDF: Teskt zostaje zamieniony na wektor numeryczny z wykorzystaniem modelu TF-IDF
  4. Analiza sentymentu (VADER): W celu glebszej analizy wyznaczane sa cechy emocjonalne tresci: compound, positive, negative, neutral
  5. Klasyfikacja: Wytrenowany model ML przewiduje czy artykul jest Prawdziwy czy Falszywy
  6. Prezentacja wyniku: Uzytkownik otrzymuje etykiete oraz poziom pewnosci predykcji
Zastosowane modele
  • Logistic Regression
  • Random Forest
  • LightGBM

Modele zostaly porownane na podstawie metryk: Accuracy, Precision, Recall oraz F1-score. Najlepszy model jest wybierany automatycznie na podstawie najwyzszej wartosci F1-score

Technologia
  • Python 3.10
  • Flask 2.x - warstwa aplikacji webowej
  • scikit-learn - trenowanie oraz ewaluacja modeli ML
  • NLTK (VADER) - analiza sentymentu
  • LightGBM - model gradient boosting
  • Matplotlib - wizualizacja metryk i macierzy pomylek
  • Bootstrap 5 - interfejs uzytkownika (style)
